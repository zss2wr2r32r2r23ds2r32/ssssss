HOW TO RUN TUFF MACRO

Tuff Macro is Natro Macro with the name changed and a black/purple UI.
Nothing else was changed.

1. Download TuffMacro.zip and extract it.
2. Open the TuffMacro folder.
3. Double-click START.bat
   AutoHotkey32.exe is already inside submacros, same as Natro.

Windows only. Open Bee Swarm Simulator, claim a hive, then start the macro.
