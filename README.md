# Avix Studios

Desktop helper for Minecraft Java configs. It catalogues chat symbols, converts text to small-caps, builds Birdflop-style colour codes, and restyles plugin YAML — including bounty-head lore — without a paid API.

The window title is **Avix Studios**. A Windows build produces `AvixStudios.exe`.

## Features

- **Emojis** — searchable catalogue (weapons, tools, weather, status, and more). Click a symbol to copy it. Add your own character, name, and category; custom symbols are saved locally.
- **Small Font** — live `ᴛᴜʀɴ ᴛᴇxᴛ ʟɪᴋᴇ ᴛʜɪs` converter. A–Z map to the phonetic small-caps alphabet, spaces stay spaces, and unmapped characters (including `s` and `x`) are left as-is. Optional placeholder protection.
- **Colour** — colour stops, a live gradient preview, and editable outputs for `&#RRGGBB`, `&x&r&r&g&g&b&b`, `§x§r§r§g§g§b§b`, MiniMessage `<#RRGGBB>`, a MiniMessage `<gradient>`, and the nearest legacy `&` code.
- **AI Config** — local rewriter for pasted YAML. Presets: **Bounty head**, **Recolour accent**, **Small-font labels**. Bounty lore follows the crimson small-font pattern (`[ʙᴏᴜɴᴛʏ]`, coloured `|` description lines, `☀` / `✎` stat lines) and keeps placeholders such as `%player%`. An OpenAI-compatible endpoint can be turned on in Settings; core features never need a key.

Custom emojis and settings are stored in Electron's `userData` directory as `avix-store.json`. The browser preview uses `localStorage` under the same shape.

## Develop

Requires Node.js 20+.

```bash
npm install
npm run dev
```

`npm run dev` starts Vite and Electron together. For the interface in a browser:

```bash
npm run dev:web
```

Then open http://127.0.0.1:5173.

```bash
npm test
npm run typecheck
```

## Windows executable

On Windows:

```bash
npm install
npm run build:win
```

`electron-builder` writes an NSIS installer and a portable exe to `release/`:

- `AvixStudios-Setup-<version>.exe`
- `AvixStudios-<version>-portable.exe`

The installed binary is `AvixStudios.exe`. The app id is `com.avixstudios.desktop`. Icons are generated by `npm run icons` (also invoked by the build scripts) into `build/icon.png` and `build/icon.ico`.

### From Linux

`npm run build:win` cross-compiles, then stops if [Wine](https://www.winehq.org/) is missing. Wine is required to stamp the exe resources and to build the NSIS installer and portable exe.

Without Wine, this still produces the application binary:

```bash
npm run build:win:dir
```

Output: `release/win-unpacked/AvixStudios.exe`. That command skips resource editing, so the Windows icon and version info are applied when you build on Windows or with Wine via `npm run build:win`.
